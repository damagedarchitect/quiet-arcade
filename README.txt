QUIET ARCADE - 100 games, no ads, no accounts, works offline

PHONE (iPhone or Android) - install it as an app:
  1. Put this folder on a free static host: drag the zip onto app.netlify.com/drop
     or Cloudflare Pages (Workers & Pages > Create > Drag and drop).
  2. Open the link once.  iPhone: Safari > Share > Add to Home Screen.
     Android: Chrome > menu > Install app.
  3. From then on it opens from the home-screen icon and works with no internet.
     Android: long-press the icon for Surprise me, Jump back in and Daily quests.
  Share the LINK, not the file: chat apps open .html files in a viewer that can't install.

COMPUTER: double-click quiet-arcade.html (the single file next to this kit).

Gestures and buttons: the phone's back button or back swipe (and the browser's Back,
or Esc) closes the game you are in, then any open sheet. Nothing is lost.

Language: Settings (top-right on the home screen) > English / Arabic / Korean.
Progress: Settings > Backup > Copy, then paste it into another copy to move it.
Tilt Maze can use the phone's motion sensor; iPhone asks for permission the first time.
