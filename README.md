# Quiet Arcade

100 games. No ads, no accounts, works offline once installed.

**Play:** https://damagedarchitect.github.io/quiet-arcade/

## Install it on a phone
- **Android (Chrome):** open the link, then menu ⋮ → **Install app** (or **Add to Home screen**).
  Long-press the icon for *Surprise me*, *Jump back in* and *Daily quests*.
- **Samsung Internet:** menu → **Add page to** → **Home screen**.
- **Xiaomi / Redmi / POCO:** if no icon appears, allow it first: Settings → Apps → Chrome → Other permissions →
  **Home screen shortcuts**, then add it again.
- **iPhone (Safari):** Share → **Add to Home Screen**.

After the first open it works without internet. Updates arrive by themselves: the app picks up the new version the
next time it is opened (on the home screen, or as soon as you leave a game).

Progress is saved on each phone. To move it: Settings → Backup → Copy, then paste it on the other phone.
